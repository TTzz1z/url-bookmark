网址收藏夹 Windows 便携版
===========================

启动方法
--------
1. 完整解压 ZIP，不要直接在压缩包预览窗口中运行。
2. 双击 start.bat。
3. 程序会选择 3000—3010 之间的可用端口并自动打开浏览器。
4. 保持命令窗口打开；关闭窗口或按 Ctrl+C 即可停止服务。

本包已经包含 Node.js 与生产依赖。启动不需要安装 Node.js，不需要执行 npm install，
也不需要管理员权限。收藏公网文章时仍然需要网络连接。

数据与备份
----------
- 数据库：data/bookmarks.db
- 本地图片：data/assets/
- 升级或移动前，请先关闭应用，再双击 backup.bat 创建备份。
- 需要还原时，关闭应用后运行：restore.bat backups\backup-YYYYMMDD-HHMMSS
- 本发布包不包含开发者的真实收藏数据，第一次启动会自动创建空数据库。

端口设置
--------
默认会自动选择端口。需要固定端口时，可在命令提示符中运行：

  set PORT=3200
  start.bat

安全边界
--------
服务只监听 127.0.0.1，设计用途是单用户本地运行。不要修改为公网监听，也不要把
data 目录提交到公开代码仓库。

系统要求
--------
- Windows 10/11 x64
- 可写入的解压目录
- 使用 Chromium、Edge 或 Firefox 等现代浏览器
